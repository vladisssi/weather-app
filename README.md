# Weather App ☀️🌧️

A minimalist weather forecast application by city. Built with React, TypeScript, Axios, MUI, and caching via localStorage.

## 🔧 Tech Stack

- React + TypeScript  
- Material UI  
- Axios  
- OpenWeatherMap API  
- Caching with localStorage  

## 🚀 Getting Started

1. Install dependencies:

```bash
npm install
```
2. Create a .env file in the root directory with your OpenWeatherMap API key:
   ```
   VITE_WEATHER_API_KEY=your_api_key_here
   ```
3.Run the development server:
  ```bash
  npm run dev
  ```
